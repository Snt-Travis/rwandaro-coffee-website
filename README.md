# Rwandaro Coffee Farmers Cooperative Website

Modern responsive marketing website for Rwandaro Coffee Farmers Cooperative Ltd, built with React, TypeScript, Vite, and Tailwind CSS.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Vercel Settings

- Framework preset: Vite
- Install command: npm install
- Build command: npm run build
- Output directory: dist
